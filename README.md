# TaskMaster

Uma aplicação simples e eficaz para gerenciar sua lista de tarefas diária.

## 🚀 Tecnologias
- **React 19 + TypeScript**
- **Tailwind CSS**
- **Lucide Icons**
- **Vite & Edge Deploy (Vercel)**
- **E2B Sandbox MicroVM Isolation**

## 📦 Como Executar Localmente
```bash
# 1. Instalar dependências
npm install

# 2. Iniciar servidor de desenvolvimento
npm run dev

# 3. Compilar para produção
npm run build
```

## 🌐 Publicação
- **Gerado com:** React 19 + Vite + Tailwind CSS
- **Sandbox:** E2B Cloud MicroVM
